# Plain-Language Playbook

## Useful Request Formula

Offer this only when the user needs structure:

> On [page], change [thing I can see] so it [desired result]. Use [words, image, or link] and [show me first / make it live].

Examples:

- "On the home page, make the next event easier to notice and make it live."
- "On the event page, replace the poster with this image but show me first."
- "The top area feels crowded on my phone. Make it calmer."
- "Add this event using the details below. If anything important is missing, ask me."

## Visual Phrase Translation

| Client wording | Inspect internally | Do not assume |
| --- | --- | --- |
| "More breathing room" | Nearby gaps, internal spacing, line height, section rhythm | Increasing every space site-wide |
| "Less boxy" | Borders, filled panels, repeated card containers, corner treatment | Removing all grouping or hierarchy |
| "Make it pop" | Contrast, size, hierarchy, accent colour, surrounding quiet | Random animation or a new colour system |
| "Cleaner" | Competing elements, alignment, repetition, hierarchy | Making everything white or minimal |
| "Bigger" | Type, control, image, or whole section; inspect context | Scaling the entire page |
| "Move it up" | Natural flow and adjacent spacing | Negative margins or absolute positioning |
| "Photo is too zoomed" | Crop, focal point, aspect ratio, phone behavior | Stretching the image |
| "Modern" | Type hierarchy, spacing, restraint, interaction polish | Replacing the established brand |
| "More underground" | Dark atmosphere, editorial crop, restrained copy, less corporate framing | Making text illegible |
| "Easier to read" | Contrast, line length, size, line height, content density | Removing meaningful content |

## One-Question Clarifiers

Use only the question that changes the result:

- Location: "Is it the large event photo at the top, or the smaller event cards below it?"
- Hierarchy: "Should the event name or the ticket button be the first thing people notice?"
- Scope: "Should this change apply only on phones, or on computers too?"
- Crop: "Should I keep the whole poster visible, or fill the space and prioritize the artist's face?"
- Publication: "Would you like to see it first, or should I make the finished version live?"

## Frustration Reset

Keep it brief:

> Got it - I was working on the wrong part. You do not need the technical name. Send a screenshot or tell me the words beside it, and I will locate it.

If the user rejects a result twice, stop making small blind tweaks. Restate the visible goal and offer two meaningfully different directions.
